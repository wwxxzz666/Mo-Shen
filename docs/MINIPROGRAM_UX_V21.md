# 墨神小程序优先体验方案 v2.1

## 产品目标

用户无需理解 Multi-Agent 架构，也能完成“提出故事—确认风格—确认大纲—逐章创作—暂停恢复—导出续写”的完整任务。Agent 节点图保留为可折叠的协作详情。

## 核心旅程

1. 首页优先展示“继续创作”和“新建故事”。
2. 用户按创作目的选择灵感、故事或长篇工坊。
3. 填写故事需求和高级参数，先生成约 200 字试写。
4. 用户确认风格后创建正式任务。
5. 故事与长篇工坊在大纲完成后等待用户确认；灵感工坊可直接进入正文。
6. 正文逐章展示，用户可暂停、恢复，并随时退出页面。
7. 完成后进入成稿，创作档案、编辑、续写和导出作为后续操作。

## 三工坊定位

- 灵感工坊：快速验证题材、人物和语言感觉。
- 故事工坊：补全世界观与人物关系，大纲确认后稳定创作。
- 长篇工坊：增加连续性审校，面向伏笔、时间线和长期连载。

三个工坊均允许自定义章节数，每章最多 5000 字。差异来自协作深度，而不是人为限制故事长度。

## 任务状态

`queued → running → awaiting_outline / paused → running → completed`

异常进入 `failed`。浏览器或小程序只保存 `task_id` 和事件游标；任务、正文和进度由服务端负责。页面重开后使用 `task_id` 恢复，不重新生成已完成章节。

## 微信小程序要求

- 底部导航收口为首页、创作、书架、我的。
- Agent 图使用纵向折叠时间线，不依赖 hover 或鼠标轨迹。
- 长正文按章加载，输入内容自动保存草稿。
- 暂停发生在当前 Agent 步骤完成后，并在界面明确说明。
- API Key 不写入代码和普通日志；正式上线前增加加密保存、删除入口以及输入输出内容审核。
